# Mods

ficsit.app mods directory fork

## Uses

- [Fork of lunr.js](https://github.com/satisfactory-dev/lunr.js) for client-side search
- [Ajv Utilities](https://github.com/satisfactory-dev/ajv-utilities) to force strong types in the standalone validators.
- [Ficsit.app GraphQL API](https://ficsit.app/api-docs), to fetch the mod-related data albeit without using a GraphQL client.

## Custom Filters

Including, but not limited to:

- on/off/ignore branch stability
- on/off/ignore controller support
- on/off/ignore AI disclosure
- include/exclude/ignore tags
